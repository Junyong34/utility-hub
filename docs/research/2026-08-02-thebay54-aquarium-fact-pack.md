- 아쿠아펫랜드 홈페이지는 `경기도 시흥시 거북섬북로 54`와 전 고객 무료 주차를 안내하지만, 매장별 운영시간이 다를 수 있다고 적고 더베이54의 예약 정책은 별도로 안내하지 않는다.

사용 가능한 대안은 다음과 같다.

- 검증된 숫자로 Zento가 직접 제작한 가격 안내 그래픽
- 주소·D동·확인할 엘리베이터를 텍스트 중심으로 정리한 자체 주차 안내 카드
- 실제 현장 사진처럼 오인되지 않는 독자 제작 수조 모티프 편집 일러스트
- 직접 촬영했거나 서면 허가를 받은 사진. 이 경우 얼굴, 아동, 차량번호, 상표 노출을 검수한다.

각 사용 이미지에는 `원본 또는 제작 주체 / 권리자 / 허용 근거 / 허용 채널 / 크레딧 방식 / 확인일 / 로컬 파일`을 기록한다. 이미지에 담긴 가격·주차 정보는 본문 텍스트와 표로도 제공한다.
